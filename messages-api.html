IMessage / IEvent / ICommand

Marker interfaces in Tutan.Messages. Implementing types must be unmanaged struct.

IMessage interface
marker
interface IMessage
Root marker interface. Not used directly — implement IEvent or ICommand instead.
IEvent interface
marker
interface IEvent : IMessage
Marker for N:M notifications. Any number of subscribers may register via EventBus. Name in past tense.
ICommand interface
marker
interface ICommand : IMessage
Marker for N:1 intents. Exactly one handler is bound per command type, declared at the composition root via CommandBus.TryInstall. Name in imperative.

EventBus

Static N:M facade in Tutan.Messages.

EventBus static
method
SubscriptionToken Subscribe<T>(MessageHandler<T> handler) where T : unmanaged, IEvent
Registers a handler. Returns an integer token for unsubscription. Main thread only.
method
bool Unsubscribe(SubscriptionToken token)
Removes the handler associated with the token. Returns false if already removed. Safe during dispatch.
method
void Publish<T>(ref T message) where T : unmanaged, IEvent
Dispatches immediately to all subscribers on the calling thread. Zero-copy via ref. Main thread only.
method
void Publish<T>(T message) where T : unmanaged, IEvent
Convenience overload — one struct copy from caller to parameter. Acceptable for small messages where the ref call site is inconvenient.
method
void Enqueue<T>(in T message) where T : unmanaged, IEvent
Thread-safe enqueue. Channel creation uses a brief lock; the enqueue itself is lock-free via ConcurrentQueue<T>.
method
void DrainQueues()
Processes all pending queued messages across all channels. Call once per frame on the main thread. MessagesHost does this in LateUpdate by default.
method
int GetSubscriberCount<T>() where T : unmanaged, IEvent
Number of active subscribers for message type T.
prop
int ChannelCount { get; }
Number of distinct message types with at least one active subscriber.
method
void Reset()
Clears all subscriptions and queues. Use on scene transitions or test teardown.

CommandBus

Static N:1 facade in Tutan.Messages. Shares Publish, Enqueue, DrainQueues, and Reset with EventBus, but has no Subscribe/Unsubscribe: the single handler per ICommand type is declared once at the composition root via TryInstall.

CommandBus static
method
bool TryInstall(out string error, Action<CommandRegistry> configure)
Declares every command handler in one place. Returns true and atomically swaps in the new bindings on success. On a duplicate command type or null handler, returns false, sets error to a message naming the offending type(s), and leaves the live bus untouched. Calling it again rebuilds the bus from scratch.
method
CommandRegistry Handle<T>(MessageHandler<T> handler) where T : unmanaged, ICommand
Fluent builder method, available inside the TryInstall callback. Binds the single handler for command type T. Chain one Handle<T> per command.
method
void Publish<T>(ref T command) / void Publish<T>(T command)
Dispatches the command to its single handler. No-op if no handler is registered.
method
void Enqueue<T>(in T command) / void DrainQueues() / void Reset()
Same semantics as EventBus.

MessageHandler<T>

Delegate type in Tutan.Messages.

MessageHandler<T> delegate
sig
void MessageHandler<T>(ref T message) where T : unmanaged, IMessage
Receives the message by ref — no struct copy on dispatch. Handlers may mutate the message; subsequent handlers see the mutation in registration order.

MessagesHost

MonoBehaviour in Tutan.Messages. Calls DrainQueues() for both buses in LateUpdate. Auto-instantiated at BeforeSceneLoad with zero configuration; define TUTAN_MESSAGES_NO_AUTO_HOST to suppress the auto-spawned host and own the drain loop yourself.

MessagesHost class
method
void LateUpdate()
Calls EventBus.DrainQueues() and CommandBus.DrainQueues(). Override or detach if you need a different drain cadence.
MessagesBootstrap static
method
[RuntimeInitializeOnLoadMethod] static void Bootstrap()
Creates a hidden persistent [MessagesHost] GameObject at BeforeSceneLoad so both buses are drained every LateUpdate with no setup. Define TUTAN_MESSAGES_NO_AUTO_HOST to skip spawning the host and drive draining yourself. Command handlers are bound explicitly at your composition root via CommandBus.TryInstall — there is no reflection-based auto-install.

MessagesInstrumentation

Static editor-only diagnostics surface in Tutan.Messages. All hooks gated behind [Conditional("UNITY_EDITOR")] and [Conditional("TUTAN_MESSAGES_DEBUG")] — stripped from release player builds.

MessagesInstrumentation static
field
bool Enabled
Master switch. When false every instrumentation hook short-circuits on the first branch (cost: one bool check per Publish).
field
bool CapturePayloads
When true, message structs are boxed into records so they can be inspected. Adds one boxing allocation per Publish/Enqueue. Off by default; the Messages Console turns it on automatically while the window is open.
method
Record[] Snapshot()
Returns a copy of the ring buffer. Allocates — keep off the hot path. Each record exposes Bus, Op, MessageType, frame, and timestamp.

EventReference / CommandReference

Serializable wrappers in Tutan.Messages that let designers pick a message type and edit its payload from the Inspector. Not for runtime hot paths — publishing involves JSON deserialization, Activator.CreateInstance, boxing, and a reflected generic Publish invocation.

EventReference serializable
method
void Publish()
Synthesizes the selected IEvent struct from inspector-edited fields and dispatches it via EventBus. Boxes the struct and uses reflection.
CommandReference serializable
method
void Publish()
Same as EventReference.Publish but dispatches through CommandBus. Constrained to ICommand types in the inspector dropdown.

The inline reflection editor renders int, float, bool, string, Vector3, Color, and any enum. A field literally named Timestamp is skipped and auto-populated at publish time (float → Time.time, double → (double)Time.time, long → DateTime.UtcNow.Ticks).

[EventType] / [CommandType] attributes

Parameterless attributes that decorate a string field so the Inspector renders it as a dropdown of message types, storing the selected AssemblyQualifiedName. The base-type filter is baked in; the runtime field type and storage format are unchanged from the previous parameterized [MessageType].

EventTypeAttribute attribute
usage
[EventType] public string eventType;
Dropdown of all concrete IEvent types in loaded assemblies.
CommandTypeAttribute attribute
usage
[CommandType] public string commandType;
Dropdown of all concrete ICommand types in loaded assemblies.
