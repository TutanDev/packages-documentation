com.tutan.functional

Functional

Null-safe, railway-oriented types for Unity. Optional<T>, Result<T>, and composable extensions that make errors impossible to ignore.

Example.cs 
// Optional<T> — no more null checks
Optional<Player> player = FindPlayer(id);

player
    .Then(p => p.Inventory)
    .Then(inv => inv.GetWeapon("sword"))
    .Match(
        onNone: () => Log("No sword found"),
        onSome: sword => Equip(sword)
    );

// Result<T> — errors you can't ignore
Result<Order> result = PlaceOrder(request);

result
    .Then(order => Validate(order))
    .Then(order => Save(order))
    .Match(
        onError: err => Reporter.Error(err.Message),
        onSuccess: order => Confirm(order)
    );

Optional<T>

Null-safe value wrapper. IsSome/IsNone, pattern matching, implicit conversions from T and None.

Result<T>

Success-or-error railway. Chain operations with .Then(), recover with .Or() and .OrElse().

Error Type

Immutable, composable errors with inner error chains and optional machine-readable codes. Implicit conversion from string.

Async Support

UniTask counterparts for the core operators on Optional and Result, so async pipelines read like sync ones. Optional: enabled when UniTask is installed.

com.tutan.messages

Messages

Standalone zero-allocation pub/sub. struct messages dispatched by ref, thread-safe enqueue from worker threads, disposable subscriptions — built for 72–120 Hz XR frame budgets.

EventBus & CommandBus

N:M event fan-out and N:1 command intents — two static facades, one zero-GC dispatcher underneath.

Zero-GC Dispatch

ref T handler signature avoids struct copies. Disposable subscriptions avoid delegate-equality bugs. No allocations on the hot path.

Thread-Safe Enqueue

Push from network or decode threads with Enqueue; handlers run on the main thread when DrainQueues() fires in LateUpdate.

Standalone & Asset Store-Ready

No dependencies on the rest of the Framework. Ships independently and is also published to the Unity Asset Store.

Teleport.cs 
using Tutan.Messages;

// Define a message — must be a struct
public struct PlayerTeleported : IEvent
{
    public Vector3 Origin;
    public Vector3 Destination;
    public float Duration;
}

// Subscribe — get a disposable Subscription, no -= operator
Subscription subscription = EventBus.Subscribe<PlayerTeleported>(
    (ref PlayerTeleported msg) => StartFade(msg.Duration));

// Publish — zero copy via ref
var msg = new PlayerTeleported { Duration = 0.4f };
EventBus.Publish(ref msg);

// From any thread — handler still runs on main
EventBus.Enqueue(msg);

// Clean up by disposing — or .AddTo(this) to auto-dispose
subscription.Dispose();

com.tutan.logging

Logging

A structured log for Unity 6. Records are typed data, not text: an event is declared once as a static partial method, a source generator writes the method a program calls, and an error brings the records that led to it.

SaveLog.cs 
using Tutan.Logging;

// Declare once - the generator writes log.Saving and log.Saved
[LogCategory("game.save")]
internal static partial class SaveLog
{
    [LogScope(LogLevel.Information, "Saving slot {Slot}")]
    static partial void Saving(int slot);

    [LogEvent(LogLevel.Information, "Saved slot {Slot} as {File}")]
    static partial void Saved(int slot, string file);
}

// Write through the Log the code was handed
using LogScope saving = _log.Saving(slot);
saving.Log.Saved(slot, file);

// Test against records as values
MemoryRecord saved = logged.Events
    .Single(r => r.Event == SaveLog.Events.Saved);
Assert.That(saved.Field("Slot"), Is.EqualTo(3));

Declared Events

A declaration names the event's fields and nothing else. The generator writes a Log extension method beside it, with the call site the compiler fills in.

No Allocation at the Call

An event that is off costs one compare. One that is on copies its values into three fixed rings under a short lock; strings and exceptions are kept by reference.

Clickable Call Sites

A Console row ends with a link to the file and line that wrote it, and double-clicking the row opens it. Every record also carries Time.frameCount.

Backlog & JSON Lines

A sink writes the latest records below its level that share an error's scope before the error, marked as context. One self-describing JSON lines file per session, with the oldest pruned.
