IMessage / IEvent / ICommand

Marker interfaces in Tutan.MessageBus. Implementing types must be unmanaged struct.

IMessage interface
marker
interface IMessage
Root marker interface. Not used directly — implement IEvent or ICommand instead.
IEvent interface
marker
interface IEvent : IMessage
Marker for N:M notifications. Any number of subscribers may register via EventBus. Name in past tense.
ICommand interface
marker
interface ICommand : IMessage
Marker for N:1 intents. Exactly one subscriber may register via CommandBus; a second Subscribe call throws. Name in imperative.

EventBus

Static N:M facade in Tutan.MessageBus.

EventBus static
method
SubscriptionToken Subscribe<T>(MessageHandler<T> handler) where T : unmanaged, IEvent
Registers a handler. Returns an integer token for unsubscription. Main thread only.
method
bool Unsubscribe(SubscriptionToken token)
Removes the handler associated with the token. Returns false if already removed. Safe during dispatch.
method
void Publish<T>(ref T message) where T : unmanaged, IEvent
Dispatches immediately to all subscribers on the calling thread. Zero-copy via ref. Main thread only.
method
void Publish<T>(T message) where T : unmanaged, IEvent
Convenience overload — one struct copy from caller to parameter. Acceptable for small messages where the ref call site is inconvenient.
method
void Enqueue<T>(in T message) where T : unmanaged, IEvent
Thread-safe enqueue. Channel creation uses a brief lock; the enqueue itself is lock-free via ConcurrentQueue<T>.
method
void DrainQueues()
Processes all pending queued messages across all channels. Call once per frame on the main thread. MessageBusHost does this in LateUpdate by default.
method
int GetSubscriberCount<T>() where T : unmanaged, IEvent
Number of active subscribers for message type T.
prop
int ChannelCount { get; }
Number of distinct message types with at least one active subscriber.
method
void Reset()
Clears all subscriptions and queues. Use on scene transitions or test teardown.

CommandBus

Static N:1 facade in Tutan.MessageBus. Same API surface as EventBus, but constrained to ICommand with the additional rule that Subscribe<T> throws if a handler for T already exists.

CommandBus static
method
SubscriptionToken Subscribe<T>(MessageHandler<T> handler) where T : unmanaged, ICommand
Registers the single handler for command type T. Throws InvalidOperationException if a handler already exists.
method
bool Unsubscribe(SubscriptionToken token)
Removes the handler. After unsubscribe, a new Subscribe for the same command type is allowed.
method
void Publish<T>(ref T command) / void Publish<T>(T command)
Dispatches the command to its single handler. No-op if no handler is registered.
method
void Enqueue<T>(in T command) / void DrainQueues() / void Reset()
Same semantics as EventBus.

MessageHandler<T>

Delegate type in Tutan.MessageBus.

MessageHandler<T> delegate
sig
void MessageHandler<T>(ref T message) where T : unmanaged, IMessage
Receives the message by ref — no struct copy on dispatch. Handlers may mutate the message; subsequent handlers see the mutation in registration order.

SubscriptionToken

readonly struct in Tutan.MessageBus. The only mechanism for unsubscription — no -= operator.

MessageBusHost

MonoBehaviour in Tutan.MessageBus. Calls DrainQueues() for both buses in LateUpdate. Auto-instantiated at BeforeSceneLoad unless TUTAN_MESSAGEBUS_DISABLE_AUTOBOOTSTRAP is defined.

MessageBusHost class
method
void LateUpdate()
Calls EventBus.DrainQueues() and CommandBus.DrainQueues(). Override or detach if you need a different drain cadence.
MessageBusBootstrap static
method
[RuntimeInitializeOnLoadMethod(BeforeSceneLoad)] static void Bootstrap()
Creates a hidden persistent [MessageBusHost] GameObject. Stripped from the build entirely when TUTAN_MESSAGEBUS_DISABLE_AUTOBOOTSTRAP is defined.
