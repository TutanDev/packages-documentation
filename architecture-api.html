Attributes

Runtime types live in namespace Tutan.Architecture. A type is tracked when it, or its assembly, carries a layer attribute.

LayerAttribute Attribute
ctor

Assigns the type to the given layer. Targets classes and interfaces; not inherited; one per type.
prop
LayerId Layer { get; }
The layer this type belongs to.
prop
string Name { get; set; }
Optional display name for editor tooling.
prop
string Description { get; set; }
Optional description for editor tooling.
Shorthand Attributes Attribute
AttributeClassEquivalent to
[Client]ClientAttribute[Layer(LayerId.Client)]
[Manager]ManagerAttribute[Layer(LayerId.Manager)]
[Engine]EngineAttribute[Layer(LayerId.Engine)]
[ResourceAccess]ResourceAccessAttribute[Layer(LayerId.ResourceAccess)]
[Resource]ResourceAttribute[Layer(LayerId.Resource)]

Each is a sealed LayerAttribute subclass with a parameterless constructor and no extra behavior.

ctor

The closed set of layers and the single source of truth for layer identity, ordered top to bottom by volatility rank.

ValueMeaning

Settings & CI

The enforcement mode decides how loudly findings are reported after every domain reload. Nothing else is configurable.

FrameworkSettings ScriptableObject
prop
EnforcementMode EnforcementMode { get; }
The current enforcement level.
method
static FrameworkSettings GetOrDefault()
Loads the asset from Resources, or returns a non-persisted default instance in WarningsOnly. Never null.
method
static FrameworkSettings GetOrCreateAsset()
Returns the saved asset, creating it at Assets/Resources/Framework/FrameworkSettings.asset when missing.
EnforcementMode Enum
ValueBehavior
OffNo automatic validation
WarningsOnlyEvery finding is logged as a warning
ErrorsForCoreEach finding keeps its own severity
StrictEvery finding is logged as an error
CIValidator static class
method
static void Run()
Headless batch-mode entry point. Scans, validates, writes architecture-report.json, and exits with code 1 on any Error-severity finding, 0 otherwise.
