SerializableOptionalDrawer editor

CustomPropertyDrawer in the Tutan.Functional.Editor assembly, registered for the open generic SerializableOptional<>, so it applies to every closed SerializableOptional<T>. Renders a toggle bound to _hasValue next to the _value field, which is enabled only while the toggle is on. Result<T>

readonly record struct in Tutan.Functional. Built via Success(value) or an implicit cast from T or Error. default(Result<T>) is an error carrying default(Error) (Message == null, ToString() == ""), so a zeroed struct never masquerades as success.

Validator<T>

A delegate type: Result<T> Validator<T>(T t). Combine with FailFast or HarvestErrors from the F module.

F module — Validation static
method
Validator<T> FailFast<T>(params Validator<T>[] validators)
Runs validators in order. Stops and returns the first failure.
method
Validator<T> HarvestErrors<T>(params Validator<T>[] validators)
Runs all validators. Accumulates all failures into a composite Error.

Both combinators also have an IEnumerable<Validator<T>> overload.
